# IzviniteVpn

Android VPN-клиент с интерфейсом на Flutter и движком sing-box.

- Название: IzviniteVpn
- Автор интерфейса: Юсупов И.
- Подписка: `https://github.com/FLAT447/v2ray-lists/raw/refs/heads/main/BLACK_LTE.txt`
- Автообновление: каждые 5 часов, пока приложение активно; при возвращении приложения на экран проверяется, не истёк ли интервал.
- Задержка: HTTP-проверка через VPN-туннель, а не ICMP ping.

## Сборка APK прямо с телефона через GitHub

1. Создай репозиторий на GitHub.
2. Загрузи в него всё содержимое этого ZIP (включая скрытую папку `.github`).
3. Открой вкладку **Actions**.
4. Выбери **Build IzviniteVpn APK** и нажми **Run workflow**.
5. Дождись зелёной галочки.
6. Открой завершённый запуск и скачай `IzviniteVpn-debug-apk` из Artifacts.
7. Распакуй скачанный ZIP и установи APK.

Сборка выполняется на серверах GitHub. Android Studio и ПК не нужны. Для загрузки файлов можно использовать браузер телефона в режиме «Версия для ПК».

## Важно

- Этот архив содержит исходный проект и workflow, а не готовый APK. APK появится только после успешной облачной сборки.
- Для автоматического обновления каждые 5 часов приложение должно быть открыто; при возвращении в приложение подписка проверяется повторно. Надёжная фоновая периодическая синхронизация после принудительного закрытия приложения пока не реализована.
- Подписка загружается с указанного GitHub URL. Доступность серверов, корректность каждого узла и совместимость всех протоколов зависят от содержимого подписки и провайдера.
- Реальная задержка доступна после подключения.
- Используется sing_box (GPL-3.0-or-later). Публикуя или распространяя изменённую сборку, соблюдай GPL и включай соответствующий исходный код и уведомления.
- Debug APK подписывается отладочным ключом GitHub runner. Для личной установки подходит; для публикации нужен собственный release keystore и отдельная защищённая настройка секретов.

## Технологии

Flutter, Dart, `sing_box` 1.x, Android `VpnService`, sing-box/libbox.
