# IzviniteVpn v2

Flutter Android-клиент на sing_box и отдельный Node.js API авторизации.

## Подготовлено
- Оранжевая тёмная тема, вход по нику и ключу, принудительная смена первоначального пароля администратора.
- Импорт подписки BLACK LTE; список серверов, задержка каждого, сортировка по лучшему результату, ручной выбор, авто-селектор, история последних серверов.
- Панель администратора: создание пользователей, ключи на 7/30/90 дней или бессрочно, лимит 1/2 устройств, поиск по нику/точному ключу, блокировка, отзыв ключа, журнал событий и статистика.
- Backend: Node.js, SQLite, bcrypt-хеши ключей и JWT.

## Перед первой сборкой
1. Размести папку backend на сервере с Node.js 22 и постоянным диском для SQLite.
2. Настрой переменные окружения из backend/.env.example: ADMIN_USERNAME=Aqsone, ADMIN_BOOTSTRAP_KEY (временный ключ), JWT_SECRET (случайная строка минимум 32 символа), DATABASE_FILE.
3. Первоначальный ключ должен быть установлен в переменную окружения хостинга; после первого входа приложение потребует заменить его на пароль длиной не менее 12 символов.
4. Включи HTTPS. Не сохраняй секреты в GitHub.
5. В GitHub Settings → Secrets and variables → Actions → Variables добавь API_BASE_URL — HTTPS-адрес API без завершающего слеша.
6. Запусти workflow Build IzviniteVpn APK; артефакт называется IzviniteVpn-arm64-apk.

## Ограничения
- Это исходный код, не размещённый сервис. Backend нужно развернуть отдельно и проверить по HTTPS.
- Уведомления администратора пока реализованы журналом событий в панели, не push-уведомлениями ОС.
- До подключения pingServers проверяет TCP handshake; UDP-протоколы могут не иметь корректного результата в этом режиме.
- Конкретную подписку и соединение нужно проверить на реальном Android-устройстве до признания сборки рабочей.
- Сборка ARM64 предназначена для современных Android ARM64 устройств.
